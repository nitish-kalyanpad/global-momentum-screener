Run the screen from this page

One tap starts a fresh run on GitHub, and the page reloads with the new results about a minute later. For that, this browser needs a GitHub token that is allowed to run this repository's workflow.

  1. Open GitHub's new fine-grained token page and give the token a name and an expiration date.
  2. Under Repository access, choose Only select repositories and pick .
  3. Under Permissions, add Actions and set it to Read and write. Leave everything else as it is.
  4. Generate the token, copy it and paste it here.

The token is saved only in this browser. Never put it in the repository or share it.

Or run it on GitHub and reload this page when it finishes.
